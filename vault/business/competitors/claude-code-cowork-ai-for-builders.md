# Claude Code & CoWork: AI for Builders

Maven course by Aki Wijesundara (PhD, ML) and Manu Jayawardana, via "The AI Internship." Direct competitor to [[me/goals|James's Maven cohort]] — same exact topic pairing (Claude Code + Cowork).

## Format
Single 3-hour live session (not a multi-week cohort). Cheapest entry point, lowest time commitment of the three direct competitors.

## Audience
Zero-technical-experience pitch — founders, PMs, designers, "tech-curious" professionals. Promise: ship a working system same day.

## Positioning
Broadest possible audience, shallow depth. Bring-your-own-paid-Claude-account, hands-on live build.
